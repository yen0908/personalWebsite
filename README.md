# 黃柏諺 Po-Yen Huang｜個人品牌網站

以純靜態 HTML 與 CSS 製作的個人品牌單頁網站，介紹個人背景、專案、學經歷、技能與聯絡方式。

## 專案內容

- `index.html`：網站頁面與樣式
- `assets/profile.jpg`：個人照片
- `assets/po-yen-huang-resume.pdf`：英文履歷

## 預覽

直接以瀏覽器開啟 `index.html` 即可瀏覽，無需安裝套件或執行建置流程。

也可以在專案目錄啟動本機靜態伺服器：

```bash
python3 -m http.server 8000
```

接著開啟 <http://localhost:8000>。
